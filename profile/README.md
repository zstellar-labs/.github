# ZStella Labs

> **The privacy layer for payments on Stellar**

![Built on Stellar](https://img.shields.io/badge/built%20on-Stellar-7D00FF?style=for-the-badge&logo=stellar&logoColor=white)

Deposit, pay, and cash out without revealing amounts or the sender → receiver link.

## At a glance

| Area | What it means |
| --- | --- |
| Amount privacy | transfers that do not publish the value moved |
| Link privacy | the sender → receiver relationship is not reconstructable from the chain |
| Groth16 / BN254 | proofs verified in a Soroban contract while the witness stays client-side |

## Part of the Stellar ecosystem

This project is part of the **Stellar** ecosystem, built with **Soroban** for on-chain logic and public, auditable settlement.
